# abilix-partner-CH910

基于上传的 abilix-partnerx-CH820.zip 制作的中英文网页 Demo。默认中文，可通过 EN 切换英文。原 CH820 文件未修改。

## 打开网页

- 直接用 Edge 或 Chrome 打开本目录 index.html。网页主体及新增资料可离线访问。
- 也可运行 npm start，访问 http://localhost:4910。需要 Node.js，无需 npm install。
- WER、旧官网和旧下载库为外部链接，需要网络。

## 2026-09-11 框架修订

依据更新后的框架文档，在 CH910 基础上减少页面层级与重复跳转。

- 首页：全球开创者、SITA 公司理念、发展历程、可就地展开的新闻报道。
- 产品主页：保留原首屏与小星介绍，仅介绍 Krypton / SK 两大系列，不放课程跳转。
- 教育机器人：进入系列后，在同一页切换学校/竞赛等对应场景和型号详情，无需另开型号页。
- 解决方案：恢复 CH820 概览正文，依次展示三大场景滚动模块、方案选择及页内详情。
- WER：恢复 CH820 站内界面，保留外跳官网；Resources 恢复原布局，FAQ 和下载功能保留。
- Stories：海报、公司概况、未来伙伴；移除重复时间线及未来伙伴区的商务合作跳转，页脚商务入口保留。
- 删除页面资料引用及其链接；资源中心的实际下载文件保留。
- 文本框统一 5px 圆角，操作按钮采用胶囊形，斜箭头改为 Inter Bold 横向箭头，下划线跳转改为按钮。

小星内的课程跳转保留。未涉及的主体文案、素材和原有动画继续沿用。

## 视觉与交互

沿用原站 1200px 内容宽度和蓝白主色。新增模块按 8pt 间距组织；桌面 H1 64/76px、H2 40/48px、卡片标题 24/32px、正文 18/30px，手机端响应式缩放。

保留首页淡入轮播、产品系列展开、解决方案滚动切换及小星图集交互。首页新增图片鼠标视差和研发区滚动显现两种动效；支持减少动态效果偏好及轮播暂停。

## 主要文件

```
assets/
index.html
styles.css
app.js
package.json
server.js
README.md
content-manifest.json
```

- assets/：页面图片、字体及可下载的公司资料。
- index.html：网页入口，仅加载一份脚本和一份样式。
- app.js：页面、内容、路由及交互的统一源文件。
- styles.css：统一样式文件，按原有优先级保留响应式和动效规则。
- package.json / server.js：无需安装依赖的本地预览服务。
- content-manifest.json：资料文件与原始来源的对应清单。

维护时直接修改 app.js 和 styles.css，无需再创建版本补丁文件。清理前备份保存在项目外的 .ch910-work/before-cleanup/，不包含在交付包内。

此版本为静态 Demo。原小星页的价格、库存、评价与购物流程沿用 CH820 展示内容，未接入交易后端。
